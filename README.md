# SPT-PikLiteHM-TTTEEE-likelihood
This likelihood is inspired by the one proposed and used in &lt;a href="https://iopscience.iop.org/article/10.3847/1538-4357/acfed0">Kable et al.&lt;/a>. The latter is constructed performing a false cut to the covariance matrix, namely "inflating" the errors relative to the block TT from $\ell$=650, in order to make the $\chi^2$ too large above it.
